
# Optopatch–OPS Platform

### Integrating Optical Electrophysiology, Optical Pooled Screening, and Functional Genomics

## Overview

Welcome to the **Optopatch–OPS Platform**, a collaborative research and code-sharing initiative focused on integrating **Optopatch** with **Optical Pooled Screening (OPS)** to investigate the relationship between genetic perturbations and neuronal electrophysiology.

Our goal is to bridge the gap between genotype and cellular function by combining high-throughput optical electrophysiology, image analysis, sequencing-based genetic identification, and computational data analysis.

This GitHub organization provides a centralized platform for sharing analysis pipelines, computational tools, and research code developed through our collaborative efforts.

## Research Areas and Code Repositories

The platform hosts code and computational tools covering several interconnected research areas:

### 1. Automated Optical Electrophysiology Analysis

- Automated processing of Optopatch fluorescence videos
- Motion correction, segmentation, and fluorescence trace extraction
- 
### 2. Single-Neuron Electrophysiological Feature Extraction

- Extraction of action potential waveform features
- Quantification of neuronal firing patterns and excitability
- Analysis of single-cell electrophysiological phenotypes

### 3. Optical Pooled Screening (OPS)

- Image processing and analysis for optical pooled screening
- Sequencing data processing and decoding
- Genetic perturbation identification
- Spatial mapping of genetic identities

### 4. Optopatch–OPS Data Integration

- Registration and alignment of Optopatch and OPS datasets
- Linking electrophysiological measurements to genetic perturbations
- Cell-level data matching and quality control
- Construction of integrated genotype–phenotype datasets

### 5. Genetics-Based Population Analysis

- Population-level analysis of electrophysiological phenotypes
- Identification of genotype-dependent functional changes
- Statistical analysis and visualization
- Multidimensional phenotyping and computational modeling

Additional repositories, analytical tools, and workflows will be added as the platform develops.

## Collaboration and Contributions

This GitHub organization is maintained by the **Optopatch–OPS collaboration team**.

We aim to facilitate code sharing, reproducible analysis, and collaborative development across participating research groups.

Team members are encouraged to:

- Share well-documented analysis scripts and computational tools.
- Provide clear instructions and dependencies for reproducibility.
- Use GitHub for version control and collaborative code development.
- Report issues, suggest improvements, and contribute to existing repositories.
